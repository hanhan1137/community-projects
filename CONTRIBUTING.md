# Contributing

Thanks for helping keep the AtlasOmnia Community Projects directory useful.

## Submission requirements

Please open a pull request that adds or updates a single factual entry with:

- project name;
- one-sentence description grounded in the project's own public source;
- a public repository, release page, product page, or the exact Discord showcase post;
- license or availability status when stated by the source; and
- a clear label for commercial, closed-source, preview-only, or Discord-only projects.

## Listing standard

This is a discovery directory, not a certification program. Entries are **listed, not audited**. Do not claim security, compatibility, performance, affiliation, or support unless the linked primary source explicitly substantiates it.

Keep project descriptions short. Do not add credentials, install commands that contain secrets, copied private content, tracking links, or marketing claims that cannot be traced to the project source.
